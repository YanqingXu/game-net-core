run/attempt, raw samples and retained pair manifests passed independent

These are the named capacity profiles, including endpoint attempts and typed

concurrency.

[Paired benchmark 42786217774/1](https://github.com/YanqingXu/game-net-core/actions/runs/42786217774/attempts/1)
passed Linux but failed the Windows historical-baseline `connections-10000`
first recorded sample with empty stderr. Windows System Event 4227 at
2026-11-10 17:09:51 +08:00 reported TCP local-endpoint reuse exhaustion, three
seconds before the sample failure. The host had only 13,977 dynamic IPv4 TCP
ports (1024–15000). The failed run and raw artifacts are retained; they do not
count as passing performance evidence. Attempt 2 passed Windows under the
expanded port range but failed Linux p999 checks in `core.echo-64-2-workers`
(926.131 us versus 847.6165 us threshold) and `core.echo-1024-2-workers`
(1975.753 us versus 1071.35925 us threshold). Both Linux executables were
byte-identical to attempt 1, whose corresponding gate passed. This variation
does not establish that the failure was only measurement noise. The bounded
[third complete attempt](https://github.com/YanqingXu/game-net-core/actions/runs/42786217774/attempts/3)
passed both producers and the paired verifier with unchanged source,
scenarios, repetitions and budgets. All three original phase4 artifact ZIP
digests matched GitHub; both regression profiles on both platforms were
recomputed from raw samples and reproduced exactly apart from generation time.
The paired aggregate also reproduced. LF/Linux and CRLF/Windows budget hashes
were reconstructed from the same immutable source bytes with identical JSON
values. These passing samples do not remove the observed tail variability or
constitute fixed-lab HP0 evidence.
The owner authorized a temporary active-only expansion to 1024–65535, with
restoration to the original range after the rerun or after 90 minutes at most.
The original active range (start 1024, count 13977) was restored at
2026-11-10 18:16:24 +08:00 and independently queried; the administrator helper
exited. No persistent network configuration was changed.
This is an environment diagnosis, not a demonstrated candidate regression fix.
