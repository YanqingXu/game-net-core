## Scope and support

The release installs six static CMake targets: `GameNet::core`,
`GameNet::protocol`, `GameNet::transport`, `GameNet::game_session`,
`GameNet::game_logic`, and `GameNet::broadcast`. Linux/x86_64 epoll is Tier 1.
Windows/x86_64 IOCP is the required Tier 2 functional and package platform.

No binary ABI compatibility is promised before 1.0. The stable compatibility
promise covers the `GameNet::core` source contract; upper-layer targets remain
provisional. Shared libraries, TLS, HTTP, RPC, UDP, KCP, macOS, and BSD are not
supported. IOE-X1–X10 io_uring remains Linux-only, non-installed, experimental,
and outside the public backend and stable API contracts.
