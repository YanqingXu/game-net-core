## Scope and runtime contract

The candidate contains the six installed static CMake targets declared by the
v0.3 manifest: `GameNet::core`, `GameNet::protocol`, `GameNet::transport`,
`GameNet::game_session`, `GameNet::game_logic`, and `GameNet::broadcast`.
Linux/epoll remains the Tier 1 production evidence path and Windows/IOCP the
required Tier 2 functional/package path. The default-off Linux io_uring work is
not installed, and no public backend selector or production replacement is
introduced.

The promotion commit changes release policy, workflows, documentation, and
contract guards only. It changes no Core runtime owner, owner thread, callback
re-entry rule, cross-thread marshal path, or object lifetime/release rule.
